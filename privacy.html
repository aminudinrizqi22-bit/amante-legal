Privacy policy

Amante. Last updated 8 October 2026.

Amante is a personal AI assistant built and operated by its developer for their own use. This page explains what data it handles when its owner connects a Google account.

Data Amante accesses

  • Google Calendar: events on the owner's calendars, which Amante can read and, when asked, create or change.
  • Gmail: messages in the owner's mailbox, read-only. Amante cannot send, delete or modify email.
  • Basic sign-in information needed to keep the connection working.

Google data is fetched only when the owner asks Amante something that needs it, such as "what is on my calendar tomorrow?"

How the data is used

Only to answer the owner's own requests inside Amante. It is not used for advertising, not sold, and not used by the developer to train AI models.

Where the data goes and how long it stays

  • Amante runs on infrastructure controlled by its developer. Connection tokens are stored encrypted in Amante's own database.
  • To write a reply, the relevant calendar or email text is sent as part of the prompt to the AI model provider Amante uses (currently Groq).
  • What Amante reads from Google can appear in the owner's conversation, and may therefore be kept in that conversation's history and in the memories Amante extracts from it. All of this lives in the same private database.
  • Google data is not shared with anyone else.

Google API Services User Data Policy

Amante's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices

  • Remove Amante's access at any time at myaccount.google.com/permissions. Connection tokens stop working immediately.
  • Disconnect Google inside Amante, which deletes the stored tokens.
  • Ask for stored conversations and memories to be deleted by contacting the developer.

Changes and contact

If this policy changes, the date above changes with it. Questions can be sent to the support email shown on Amante's Google consent screen.
